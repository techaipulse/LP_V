 ✅ Code with Explanation

 🔹 Step 1: Import Libraries

```python
from tensorflow.keras.datasets import imdb
from tensorflow.keras.preprocessing.sequence import pad_sequences
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Embedding, Dense, GlobalAveragePooling1D
```

📌 Explanation

 `imdb` → dataset
 `pad_sequences` → equal length inputs
 `Embedding` → word vector representation

---

 🔹 Step 2: Load Dataset

```python
(X_train, y_train), (X_test, y_test) = imdb.load_data(num_words=10000)
```

📌 Explanation

 Loads top 10,000 frequent words
 Data already tokenized

---

 🔹 Step 3: Pad Sequences

```python
X_train = pad_sequences(X_train, maxlen=200)
X_test = pad_sequences(X_test, maxlen=200)
```

📌 Explanation

 Ensures all reviews have same length
 Required for neural networks

---

 🔹 Step 4: Build Model

```python
model = Sequential([
    Embedding(input_dim=10000, output_dim=32, input_length=200),
    GlobalAveragePooling1D(),
    Dense(64, activation='relu'),
    Dense(1, activation='sigmoid')
])
```

📌 Explanation

 Embedding → converts words into vectors
 Pooling → reduces dimensionality
 Sigmoid → outputs probability

---

 🔹 Step 5: Compile Model

```python
model.compile(optimizer='adam',
              loss='binary_crossentropy',
              metrics=['accuracy'])
```

📌 Explanation

 Binary classification loss
 Adam optimizer

---

 🔹 Step 6: Train Model

```python
model.fit(X_train, y_train, epochs=10, batch_size=512)
```

📌 Explanation

 Learns patterns from text data

---

 🔹 Step 7: Evaluate Model

```python
loss, accuracy = model.evaluate(X_test, y_test)
print("Accuracy:", accuracy)
```
